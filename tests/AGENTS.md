# OVERVIEW
Offline, deterministic regression suite for the analyzer and renderer.
Tests protect failure, resume, recovery, validation, and boundary behavior.

Keep this file current: when suite conventions, helpers, or the run environment change, update it in the same commit.

# LAYOUT
Flat directory: `test_*.py` files plus shared helper modules.
`audition_fixtures.py` holds bundle/script helpers; `shared_fixtures.py` holds cross-cutting helpers (Terminal, snapshot, pcm_hash, make_epub, make_serial_epub, timed_transcript, FakeEntryPoints, PARENTHESIS_TRIM_CASES, renderer_config, route_mlx_takes_to_fake_generate). Neither starts with `test_`, so discovery ignores them; add new shared helpers there, not inline copies.
`fixtures/` contains five JSON contracts: attribution semantics and speech rewrite policies v1 through v4.
`test_<module>.py` usually maps to `epub_tts_narrator/<module>.py`.
Renderer coverage uses `test_renderer_<module>.py`, with behavior files for cross module flows.
Bare helper imports work because unittest discover puts `tests/` on `sys.path`.
`test_series_bundle_tools.py` additionally inserts `scripts/legacy_series` into `sys.path`.
The real EPUB fixture is `examples/last-lantern/the-last-lantern.epub`.
Performance tests fake only planning, synthesis, and ASR boundaries; the comparison integration uses real snapshots, frozen voice stores, verification, FFmpeg assembly, timing exports, and resume. Synthetic audiobook fixtures without an EPUB explicitly set `render.require_cover=False`; production cover policy stays enabled.
Censorship tests keep whole-word source matching, mask validation, PCM fades, per-lane mixing, frame timing, and cache logic real. Fake only Whisper's alignment/model boundary. Cover repeated/ambiguous words, approved source respellings, missing/unsafe timestamps, streaming PCM equality, unchanged originals, and disabled-policy cache compatibility; never synthesize audio to repair alignment in tests or production.
Pronunciation tests keep registry inheritance, source evidence, CLI publication/resume, chunk projection, and preview compression real. Analysis must not restore independent spelling scans, pronunciation discovery, CMU suggestions, or name-classification sidecars. Compact attribution may produce sparse reviewed spoken edits and scoped controls; completed-book resume preserves saved data without preparing new edits. Manual pronunciation UI (`pronunciations`) must not require an LLM or generate suggestions; `test_name_pronunciations.py` covers the user-invoked `pronounce` (`pronounce-name`) exception with `FakeModel` guesses/part-of-speech labels and `PreviewEngine` previews: inflection phones, parts-of-speech parsing/defaults, invented words tagged without requests, restricted parts labelled once and re-chosen without requests, `LABEL_VERSION` relabelling that keeps a person's decisions, v1 record upgrade, book test sentences, `S`/`--as`, phoneme groups as consecutive engine tags, say-as spellings (`R`, possessive/capitals kept), homonym exclusion, unsure blocking, batch-checkpoint resume, block-hash relabelling, draft isolation, series inheritance, `analyze`-rerun labelling of inherited words (patched `cli.OpenAICompatibleClient`, unsure → exit 2), unfinished preview takes moving to new seeds, and plan-level phoneme controls. Legacy helper tests still cover cached proposals and exact audition-to-approval binding; synthetic audio does not prove live pronunciation quality.
Compact attribution tests cover complete ordered unit coverage, unique source anchors, full cast membership without repeated voice profiles, legacy cache reuse, sparse edit review, rejection dependencies, markup protection, and immutable source. Inline performance tests must drive midstream whisper/emotion spans and vocalizations through chunk/paragraph planning and synthesis compilation, including source resegmentation and exact-once boundary events. Fixtures prove mechanics, not audible performance quality or semantic model accuracy.
Adaptive casting tests force input/output capacity failures across more than eight leaves, prove 60,000-character initial regions and bounded concurrent execution, preserve exact source and complete candidate records, reject generic-error subdivision, and retain three-reviewer identity approval. Coverage tests bind findings to exact source anchors and stop repeat/no-progress repairs. Work bounds derive from source size, never fixed book quotas; fake runs prove mechanics, not perfect semantic casting.
Continuity tests (`test_renderer_continuity*.py`) use real adapters, cache/acceptance records, codec artifacts, FFmpeg composition, cleanup and chapter scheduling with fake model/ASR boundaries. # CONVENTIONS
Use stdlib `unittest` and `unittest.TestCase`; no pytest fixtures, markers, or conftest files.
Name classes `<Subject>Tests(unittest.TestCase)`.
Name methods as sentence length behavior descriptions, including the relevant condition.
Use `subTest` for malformed input matrices and related case tables.
Use `tempfile.TemporaryDirectory` with cleanup for filesystem tests. A CLI test with a relative output path runs in its own temporary working directory (`self.enterContext(contextlib.chdir(...))`): analysis caches live inside the output, so a relative path would otherwise write under `tests/`.
The suite must finish the same with or without a controlling terminal (it runs in the `ordered-render` tmux pane). A CLI test that can reach an interactive speaker prompt patches `epub_tts_narrator.speaker_decisions.open` to raise `OSError`, unless it deliberately supplies a fake terminal; otherwise `/dev/tty` waits for a person and the suite hangs.
For started patches, register cleanup: `self.addCleanup(patch.stopall)` or per-patch `self.addCleanup(patcher.stop)` — both are house style.
Keep tests deterministic, offline, and independent of execution order.
Never depend on prior analysis/render output under `runs/`, `dist-runs/`, or another developer-local directory. Construct temporary bundles from tracked fixtures or test-owned data and exercise the real exporter/loader.
Cover failure and resume paths, including files named `test_*_resume.py`, `test_*_retry.py`, and `test_*_recovery.py`.

# FAKING PATTERNS
| Boundary | Pattern | Canonical example |
| --- | --- | --- |
| LLM | Per file FakeClient; `complete(system, payload)` dispatches on `payload["mode"]`, scripts request IDs, deep copies `self.calls`. | `test_pipeline.py` |
| HTTP | Patch `<module>.build_opener`; return a Mock opener and `FakeResponse(io.BytesIO)` with `status`; inspect real Request fields. | `test_provider.py` |
| TTS and GPU | Replace only third party boundaries: Mock model, soundfile writer, `SimpleNamespace` segments, and `ModuleType("mlx.core")` stubs. | `test_renderer_mlx_audio_engine.py` |
| Credentials | `patch.dict(os.environ, {"...": "wrong"})`; prove ambient variables are ignored in favor of TOML configuration. | Provider tests |
FakeClient variants use constructor flags such as `invalid_text=` and `mutation=`, or local subclasses such as `FailingClient`.
Assert that truncated, NaN, inf, and int16 audio never reaches disk.
Keep live model behavior out of tests; use `scripts/validate_identity.py` for manual regression.

# GATING
| Dependency or platform | Gate |
| --- | --- |
| ffmpeg and ffprobe | `unittest.skipUnless(..., "ffmpeg/ffprobe required")` |
| Optional server dependencies | `skipUnless(importlib.util.find_spec("msgpack") ...)` or `HAS_SERVER_DEPS` |
| POSIX terminal behavior | `skipUnless(os.name == "posix", "POSIX required")`; cover pty and termios here |
Do not use pytest markers. State the missing dependency or platform in every skip reason.
Diagnostics redaction is covered by the `DO NOT ECHO` fixtures in `test_cast_evidence_diagnostics.py` and `test_attribution_review_diagnostics.py`.

# HOW TO ADD A TEST
1. Choose the mapped module or the narrow behavior file; name it `test_<module>.py`.
2. Identify the user visible outcome, including an error, malformed input, retry, or resume case.
3. Keep owned logic real; fake only network, GPU, TTS, credentials, and other external boundaries.
4. Add deterministic setup, cleanup, and a behavior named `TestCase` method.
5. Run the focused test, then the relevant subset or full suite before handoff.

# COMMANDS
The full suite runs in `.venv-renderer` with all dependencies declared in `test.requirements.txt`, including the real `boto3` client and `faster-whisper` audio decoder. Missing dependencies must be installed, not hidden by skips. No model downloads or cloud credentials are needed. Setup/update:
```sh
uv venv --python 3.12 .venv-renderer  # first setup only
uv pip install --python .venv-renderer/bin/python -r test.requirements.txt
```
Full suite: `.venv-renderer/bin/python tests/run_detached.py` (same discovery with no controlling terminal and stdin from `/dev/null`, so a test that reaches a tty prompt cannot hang an interactive shell; accepts the same discover options, e.g. `-p "test_epub.py"`; `just test` uses it; zero skips expected on the supported environment).
Single file: `.venv-renderer/bin/python -m unittest discover -s tests -p "test_epub.py" -q`
Renderer subset: `.venv-renderer/bin/python -m unittest discover -s tests -p "test_renderer_*.py" -q`

Always run through discover with `-s tests`: bare helper imports (`from test_contracts import ...`) only resolve that way; `python -m unittest tests.test_epub` fails on files with cross-imports.
